# Anand Keshari — Personal Website

This repository contains the source code for my personal website and portfolio.

The site brings together my work across cybersecurity research, security projects, and software development.

## About

The website is built to showcase:

- Cybersecurity research and responsible disclosure work
- Security-focused projects and practical learning work
- Software development projects
- Technical skills and experience
- The Cyber Pioneer and related community work
- Contact and professional information

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Express
- Google GenAI
- Motion
- Lucide React

## Getting Started

Clone the repository:

```bash
git clone https://github.com/anandksri/anandkeshari.com.np.git
cd anandkeshari.com.np
```

Install dependencies:

```bash
npm install
```

Configure any required environment variables using the project's environment example/configuration files. Do not commit API keys, credentials, or other secrets.

Start the development server:

```bash
npm run dev
```

The Vite development server runs on port `3000` by default.
